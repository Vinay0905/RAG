Run these commands in your terminal to stop and remove any active or stopped Qdrant instances (this avoids name/port conflicts):                                                                 
                                                                                                                                                                                                   
    # Stop any container running Qdrant                                                                                                                                                            
    docker stop $(docker ps -q --filter ancestor=qdrant/qdrant)                                                                                                                                    
                                                                                                                                                                                                   
    # Remove the stopped Qdrant containers                                                                                                                                                         
    docker rm $(docker ps -a -q --filter ancestor=qdrant/qdrant)                                                                                                                                   
                                                                                                                                                                                                   
  (If the command above says "requires at least 1 argument", it means there were no containers to stop/remove, which is fine).

  ### Step 2: Start Qdrant with Explicit IPv4 Loopback Bindings                                                                                                                                    
                                                                                                                                                                                                   
  Run this command to start Qdrant. By prefixing the ports with 127.0.0.1:, we force Docker to route requests through the IPv4 loopback interface directly, preventing macOS IPv6 resolution bugs: 
                                                                                                                                                                                                   
    docker run -d -p 127.0.0.1:6333:6333 -p 127.0.0.1:6334:6334 --name qdrant qdrant/qdrant
